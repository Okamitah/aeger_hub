# AEGERHUB

## Stack Technique

* **Backend :** Java 17, Spring Boot 3, Spring Data JPA
* **Simulation :** Java Scheduled Services (Calcul mathématique temps réel)
* **Base de données :** PostgreSQL 15
* **Frontend :** Vue.js 3 / Vite (Node.js 20)
* **DevOps :** Docker, Jenkins, Git
